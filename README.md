# Kouvul Vasanthaya 2026 – Raffle Draw v9
## Standalone Edition (No database, no server required)
### Developed by KLMC

---

## ⚡ How to Use

Just unzip and open `index.html` in any modern browser.
**No XAMPP, no PHP, no MySQL needed.**

---

## ✨ Features

- 🎡 Spin wheel with correct arrow-to-winner accuracy
- 📸 Photos on wheel + 1:1 winner photo display
- 📦 ZIP import: drop a ZIP with names.csv + photo files
- 📂 File import: Excel (.xlsx), CSV, TXT, Word (.docx)
- 🔀 Shuffle names before spinning
- 🏆 Winner screen with ring burst + star particles + confetti
- ⛶ True native fullscreen mode (winner screen works in FS too)
- 🔊 5 drawing sounds + 5 winning sounds + custom audio upload
- 🖼 Drag & drop background image
- 🏅 Drag & drop logo image (up to 400px)
- ✨ Logo pulse animation
- 📜 Session draw history (clears when page reloads)
- 🌐 English / Sinhala language switch
- 🔒 UI locked during spin

## 📦 ZIP Format for Photos

```
my-event.zip
├── names.csv        ← one name per line
├── John Silva.jpg   ← filename matches name exactly
├── Mary Fernando.png
└── Kasun Perera.jpg
```

## 🌐 Internet Required For
- Google Fonts (display fonts)
- JSZip library (ZIP processing)
- XLSX library (Excel import)

Everything else runs locally in the browser.
